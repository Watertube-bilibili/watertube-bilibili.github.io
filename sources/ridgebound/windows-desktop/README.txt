山野之间 · RIDGEBOUND Windows x64

Ridgebound-Setup-x64.exe 安装当前用户版本，并在开始菜单创建游戏和卸载快捷方式。
Ridgebound-Windows-x64.zip 可解压到任意目录，双击 Ridgebound.exe 启动。
请完整保留 EXE、PCK 和方向盘组件的相对位置。

系统目标：64 位 Windows 7 SP1 及以后，CPU 支持 SSE4.2，显卡驱动支持 OpenGL 3.3。
运行游戏无需浏览器或网络。Windows 7 和具体方向盘型号的实机验证以发布说明为准。

方向盘和 USB 踏板使用 Windows 上的设备驱动。连接设备后，在游戏内独立绑定方向、
油门和刹车。兼容 DirectInput 力反馈的设备可启用力反馈。首次使用请从低强度开始。
F8 可停止力反馈。

进度由 Godot 保存在当前 Windows 用户的应用数据目录。卸载程序保留进度。
便携版与同一 Windows 用户下的安装版共用桌面进度。
