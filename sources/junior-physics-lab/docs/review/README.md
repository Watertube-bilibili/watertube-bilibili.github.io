# 交互与教学质量审查

这轮审查由用户实际使用后提出的“开始后不动”“不必开始的实验硬塞开始按钮”“控件不对应真实器材”触发。此前的目录、数值和SVG合法性检查只能证明程序能运行，不能证明教学任务已经实现。

审查逐项回答：

1. 学生应该操作什么、观察什么？
2. 这是即时读数、结构观察、记录分析，还是有必要播放的时间过程？
3. 控件是否改变对应器材和相关观察，还是只换了文字？
4. 零输入、反向、断路、暂停、卸载等对照是否给出正确现象？
5. 模型计算、单位、适用条件和规范作答是否一致？

各科记录：[物理](physics.json)、[化学](chemistry.json)、[生物](biology.json)。条目中的 `limitations` 是具体支持范围；“已审查”不等于所有实物步骤都能在浏览器完成。资料分析、野外调查和制作项目按实际支持环节说明，不能与完整器材操作等同。

## 本轮结果

| 学科 | 即时交互 | 过程播放 | 审核范围 |
| --- | ---: | ---: | --- |
| 物理 | 133 | 49 | 182条逐项审查，当前6条仍为部分实现 |
| 化学 | 37 | 42 | 79条逐项审查，17条明确有限支持范围 |
| 生物 | 86 | 9 | 95条逐项审查，调查、记录分析与制作类按实际支持环节说明 |

356条默认调用和三个SVG阶段通过真实浏览器检查；100条过程播放在去除文字、数字之后，均有器材几何或物质外观变化。物理182条默认/最小/最大条件共546次真实引擎调用与SVG检查通过；19组控件比较与182条默认图中文字边界检查通过。界面另通过9组模式、声音、手动计时、取消和切换检查。上述证据不把部分实现升级为完整流程。

物理仍缺少的关键环节是：倒置漏斗流场与稳定性、盐水前后差量称重、鞋印方格计面积、细杆密度计标定、简易气压计液柱联动、吹纸条随气流变形。它们在目录中标为“部分实现”。

原始结果：[默认调用](browser-defaults.json)、[播放画面变化](playback-motion.json)、[界面交互](interaction-quality.json)、[定向独立复审](physics-independent.json)。

## 滚摆补充修复

首次发布提交 `6e5a540` 将滚摆列为下降段部分实现。本次已补最低点反卷、多次回升、冲量耗散与分辨率边界；原提交保留在Git历史中。新增模型的20组原生Godot测试、实际Web导出与7组页面交互回归已通过；整站356项默认调用与原有记录流程回归通过。这些是理想模型和软件验证，没有进行实物绳弹性、松绳或真实冲击测量。

详见[滚摆模型与验证](rolling-pendulum.md)、[科学关系结果](rolling-pendulum-science.json)、[网页交互结果](rolling-pendulum-browser.json)。

## 修复原则

- 即时交互不显示开始、暂停或播放进度；条件变动后立即更新当前观察。
- 动态实验读取过程状态，不能在开始前显示最终沉淀、最终温度或最终位移。
- 刚体运动使用Godot实际积分；静力、光学、电学、声学与热学计算在Godot科学模型中执行。JavaScript只呈现返回的轨迹和状态。
- 钢尺通过伸出长度与拨动幅度操作；手动秒表按浏览器实际时间计时。声音仅在用户操作后以较低默认音量播放。
- 自动检查同时包含科学关系断言与实际界面操作；不能仅凭SVG字符串变化认定现象正确。

新增场景拆分为独立模块和求解器，目录修改保存于生成脚本或原始补丁数据，重新生成不应丢失修复。

## 主要验证入口

- `tests/platform_browser.py`：全部目录默认模型、SVG及总体页面流程。
- `tests/interaction-quality-browser.py`：即时与过程模式、控件联动、声音、取消与切换。
- `tests/manual-timer-browser.py`：真实手动计时与暂停。
- `tests/playback-motion-browser.py`：去掉文字之后，检查每个声明为播放的项目是否真的有器材/物质外观变化。
- `tests/godot_review_models.gd`：相变平台、振源与接收、钢尺、累积法、力偶、感应条件。
- 各专项 `tests/godot_*review*.gd`、`tests/godot_apparatus*.gd`、`tests/biology-quality-browser.py`、`tests/chemistry-review-browser.py`：具体科学关系与装置行为。

浏览器回归使用真实Godot WebAssembly。测试覆盖与逐项审查共同提供证据，不替代真实器材校准或当地考试评分标准。
