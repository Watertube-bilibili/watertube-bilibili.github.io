# 内容与模型的检查约定

1. 确认教材版本、年级、章节、活动类型和公开来源。
2. 写清实验目标、器材、操作、观察、结论、控制变量、考点和易错点。
3. 数值计算依次写已知量、单位换算、公式或方程依据、带单位代入、结果、合理性检查。
4. 定性实验使用观察、比较、推理和结论，不能编造不必要的定量数据。
5. 保证页面控件确实改变模型与图示；不以通用动画替代不同实验。
6. 明确理想化条件；区分模型数据和真实实验数据。
7. 物理运动使用 Godot 刚体求解；其他科学模型必须指出其适用范围。
8. 检查参数上下限、零值、奇点、重复开始、切换实验、重置及异步结果过期。
9. 只提交原创或已获相容授权的内容，保留第三方许可。
