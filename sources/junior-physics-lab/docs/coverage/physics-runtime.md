# 物理实验运行与图形验收

验收日期：2026-10-31。对象为本项目物理目录中的 **182 条记录**，以及其对应的 25 个模型家族和各实验变体。教材来源与活动对应关系另见目录来源文件及覆盖表；本页记录运行验收，不将运行成功等同于对所有教材版本的穷尽证明。

## 计算与显示的分工

`dist/modules/physics.js` 中的 `simulate` 将实验设置、控件值交给 `GodotLab.evaluate`。Godot 未就绪或计算失败时返回错误，不使用 JavaScript 物理公式兜底。比较比热容与焦耳热时，对两组条件分别调用 Godot，将两组实际计算步骤和读数一起返回。

小车斜面、水平运动和单摆使用 Godot 刚体轨迹。SVG 按轨迹时间插值；单摆读取引擎返回的摆角，小车从右上方 A 点向左下方 C 点运动。光学、电路、热学和静态受力等使用 Godot 内的相应科学或定性求解器。图形层只安排器材、投影几何和播放进度，不自行产生科学读数。

所有器材图为原创 SVG，采用课堂课件的蓝灰、木色与红蓝标记。除基本测量、力学、热学、光学和电磁学场景外，提供纸杯电话、碘管、冷瓶凝露、霜罐、水流导光、潜望镜、角反射器、非均匀介质光路、水滴与放大镜、托里拆利装置、压水泵、微小形变瓶、溢水杯、杆秤和回滚罐等专用器材图。

## 复现

从仓库根目录启动本地静态服务器：

```sh
python -m http.server 8782 --bind 127.0.0.1 --directory dist
```

在另一个终端运行：

```sh
node tests/physics-renderers.cjs
python tests/physics-renderers-catalog.py
python tests/physics-renderers-controls.py
```

浏览器测试使用 Python Playwright 与 `/usr/bin/chromium`，会加载项目中实际的 Godot Web 引擎。使用其他端口时设置 `LAB_TEST_URL`。`tests/physics-renderers-browser.py` 另可按 `godot/model-schema.json` 遍历模型与场景。

## 模型范围的呈现

物态变化按材料和操作区分；没有实测相图的混合液不显示虚构温度或凝固比例。扩散粒子、气体、摩擦做功、眼睛矫正及部分小制作保留明确的定性或结构示意说明。液面升降、热机冲程和颜色混合使用对应求解结果；图中相对场强、波形和器材尺寸不作为真实仪器测量值。超出给定模型范围的输入由引擎说明适用范围，图形不补造结果。

以上结果对应验收时的代码与目录；后续调整求解器、控件或场景后，应重跑相关检查。
