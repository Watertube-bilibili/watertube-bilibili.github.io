# 人教版初中物理版本核验（2026-10-31）

## 核验结论

- 当前人教版独立物理科教材为八年级上册、八年级下册、九年级全一册；不能虚构“七年级上/下册人教物理”或把九全称作官方九上/九下。
- 新一轮修订八上在2024年秋使用、八下2025春使用、九全2025秋使用。出版、审定、实际启用日期应区分，不将“2024版”误认2024年已有完整九年级新版。
- 截至研究日期，课程标准另有《义务教育物理课程标准 日常修订版（2022年版2025年修订）》。已核对这一版本存在及名称，但本项目没有逐字审校2025修订课标全本，不据此宣称涵盖全部修订差异。
- 官方“物理·八年级上册”2015年产品页与九年级2015年产品页属于旧版，不能单独用于新教材目录核验。
- 当前目录总计22章92节这一数字获得二级来源交叉支持，但必须由目录页逐节确认后再作为完全性声明。

## 已完成的活动核对

- 八上：101项可操作活动候选，包括实验、演示、想想做做、拓展、项目和正文/练习中的操作；按器材与研究问题合并重复变式。
- 八下：62项活动，保留正文活动与明确栏目之间的区别。
- 九全：61项已核对活动，记录印刷页与章节；第13—18章置于网站9上，第19—22章置于网站9下，仅为网站导航分组。
- 合并目录和NCET补充共182条。活动候选数、网站实验卡数和官方目录项目数是不同口径，不能互相替代。
- `physics-coverage.json` 包含224条教材活动映射与嵌入的官方68项基线映射。直接对应、同原理变式和跨册引用分别记录，不把变式映射称作单独完整复现。
- 解释、步骤、例题与SVG均为项目原创；来源只用于核对活动和章页，不复制整页教材。
- 数据模型与实物的边界逐卡写在 `modelNote`。内容映射通过不代表所有装置细节均有数值模拟，运行质量另由实际Godot逐项测试确认。
